# VISTA-Vision-based-Intelligent-Stevenson-Thermometer-Analyzer-
# Digital Image Processing-Based Stevenson Screen 🌡️

A Raspberry Pi-based automated temperature measurement system that uses digital image processing to detect the mercury level of a thermometer inside a Stevenson Screen and convert it into a temperature reading.

## 📌 Project Overview

Traditional Stevenson Screen thermometers require manual observation and recording. This project automates the process by capturing thermometer images using a Raspberry Pi camera, processing them with OpenCV, detecting the mercury level, calculating the temperature, and logging the results automatically.

## 🎯 Problem Statement

Manual thermometer readings can be time-consuming and may introduce human reading errors. The objective of this project is to develop a camera-based system for automatic thermometer reading and temperature data logging.
